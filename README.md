# Theater Ticket Booking System | MySQL

## Project Overview

The Theater Ticket Booking System is a SQL-based database project developed using MySQL to simulate a real-world movie ticket booking system.

The project manages theater information, ticket booking, ticket cancellation, seat availability, and booking history using relational database concepts, stored procedures, transactions, and analytical SQL queries.

## Features

- Designed and created relational tables for theater, tickets, bookings, and cancellations
- Implemented ticket booking and cancellation using stored procedures
- Automatic seat availability management
- Transaction handling to ensure data consistency
- Booking and cancellation history tracking
- SQL queries for booking, revenue, and cancellation analysis
- Aggregate and window functions for data analysis

## Database Components

The project consists of the following tables:

- **Theater** – Stores theater details.
- **Ticket_Info** – Stores ticket types, pricing, and seat availability.
- **Bookings_Log** – Records ticket booking transactions.
- **Cancellation_History** – Maintains cancelled booking records.

## Technologies Used

- MySQL
- SQL
- MySQL Workbench
